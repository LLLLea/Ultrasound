A summary of several ultrasound projects



## EchoNet-Dynamic
自动化评估广泛的心脏超声参数，主要是线性测量（e.g.左心房直径和室间隔厚度）和多普勒测量（e.g.三尖瓣反流峰值速度和室间隔e’波速度）
https://github.com/echonet/dynamic

## GroundingDINO-US-SAM
提出一种基于文本 Prompt 的自动多器官超声分割框架：结合Grounding DINO与SAM2，无需点击、边界框或特定器官再训练即可完成分割
https://github.com/IMPACT-L/GroundingDINO-US-SAM

## DiffUS: Differentiable Ultrasound Rendering from Volumetric Imaging
将MRI或CT等高质量的三维医学影像转换为B型超声图像

https://github.com/gduguey/DiffUS
